# Blogicum — финальный проект

В этом спринте вам предстоит доработать Blogicum и добавить автоматическую
модерацию комментариев.

## Подготовка

1. Используйте Python 3.14.
2. Перенесите проект прошлого спринта в каталог `blogicum/`.
3. Скопируйте готовые шаблоны из `templates/` в `blogicum/templates/`.
4. Создайте и активируйте виртуальное окружение.

### Linux и macOS

```bash
python3.14 -m venv venv
source venv/bin/activate
```

### Windows PowerShell

```powershell
py -3.14 -m venv venv
venv\Scripts\Activate.ps1
```

После активации окружения обновите `pip` и установите зависимости:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Что нужно реализовать

- регистрацию, авторизацию и страницы профилей;
- создание, редактирование и удаление публикаций;
- изображения, категории, отложенные публикации и пагинацию;
- создание, редактирование и удаление комментариев;
- проверку прав авторов;
- статические страницы на CBV;
- страницы ошибок 403 CSRF, 404 и 500;
- файловый почтовый бэкенд.

## ML-модерация

Комментарий должен проверяться готовой моделью
[`cointegrated/rubert-tiny-toxicity`](https://huggingface.co/cointegrated/rubert-tiny-toxicity).

- Обучать модель не нужно — используется только inference.
- Порог токсичности `0.8` вынесите в константу.
- Загружайте модель лениво, при первом обращении.
- Выполняйте проверку в `CommentForm.clean_text`, чтобы она работала при
  создании и редактировании комментария.
- Токсичный комментарий не сохраняется, а пользователь видит ошибку формы.

При первом ручном запуске модель скачает веса из интернета. В автотестах
вызов модели замокан, поэтому скачивание не требуется.

## Проверка

После выполнения миграций проверьте проект, тесты и стиль кода:

```bash
python blogicum/manage.py migrate
python blogicum/manage.py check
pytest
flake8 blogicum
```

Перед отправкой убедитесь, что тесты и `flake8` проходят без ошибок, а
каталоги `venv/`, `media/` и `sent_emails/` не добавлены в Git.
